# game-plugin

猜图、问答与今日老婆三个小游戏，均为群聊指令。插件 ID `game`。

## 指令

### Guess

`#Guess`（别名 `#猜`）：从资源目录随机抽图并裁剪，群成员抢答。

- `Guess [关键词]`：关键词精确匹配分类名或角色名，不填时从全部图片中抽取；
- 回答格式为 `<前缀>答案`（默认 `#答案`），发送 `<前缀><前缀>`（默认 `##`）或 `Guess -f` 放弃；
- 每局最多猜 10 次，等待 99 秒；同一群同时只能有一局。

### Quiz

`#Quiz`（别名 `#问答`）：由宿主 AI 模型生成一道单选题。

- `Quiz [主题]`，默认主题 `二次元`；
- 回答选项字母，时限 5–120 秒，由题目难度决定；
- 需要宿主已配置可用的 AI 模型。

### Wife

`#Wife`（别名 `#今日老婆`）：抽取今日老婆，群友与二次元两类每天各一次。

- `Wife`：随机群友（排除自己与机器人）；
- `Wife <关键词>`：按分类名或角色名抽取二次元老婆；
- `Wife -m/--member=<用户ID>`：指定群友；
- `Wife -a/--anime=<关键词>`：指定二次元老婆；
- `-m` 与 `-a` 需要 manager 权限。

## 数据

插件数据目录按“分类/角色/变体”组织，Guess 与 Wife 共用：

```text
game/
└── 分类名/
    ├── 角色名.png
    ├── 角色名_变体.png
    └── 角色名/
        ├── 1.png
        └── 2.png
```

- 目录名是分类，文件名是角色名；`角色_变体` 表示变体，角色子目录中的图片都是该角色的变体；
- 支持 png/jpg/jpeg/gif/bmp；分类目录下以 `.` 开头的条目会跳过；
- 无配置文件。
