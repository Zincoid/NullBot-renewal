# pubg-plugin

发送 PUBG 资源地图。插件 ID `pubg`。

## 指令

`#PUBG`（别名 `#吃鸡地图`），群聊与私聊均可用。

- `PUBG`：列出全部地图名称与拼音首字母；
- `PUBG <地图>`：发送对应地图图片，地图名或拼音首字母均可。

| 地图 | 首字母 |
| --- | --- |
| 艾伦格 | `alg` |
| 米拉玛 | `mlm` |
| 维寒迪 | `whd` |
| 帝斯顿 | `dsd` |
| 荣都 | `rd` |
| 泰戈 | `tg` |

## 数据

六张地图图片随插件 JAR 分发，首次启动解压到插件数据目录；无配置文件。
