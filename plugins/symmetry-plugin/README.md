# symmetry-plugin

把图片的一半镜像到另一侧。插件 ID `symmetry`。

## 指令

`#Symmetry`（别名 `#图像对称`、`#对称`）

用法：

1. 引用图片后发送 `Symmetry [方式]`；
2. 发送 `Symmetry [方式]` 并附带图片；
3. `Symmetry [方式] <QQ号 | @用户>`：处理用户头像。

方式为 `左`/`右`/`上`/`下`（默认左，也支持 `left`/`right`/`top`/`bottom`）。多张图片或多个 @ 用户会逐张处理；图片下载上限 32 MiB。群聊与私聊均可用。

无配置文件与插件数据。
